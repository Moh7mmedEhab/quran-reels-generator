Built-in recitations stream from their listed provider when previewed or rendered; no recitation audio is bundled with the project. The catalog uses source-specific URLs and coverage rather than assuming every recording has the same file layout.

The main Mishary Alafasy Hafs Murattal is from MP3Quran.net and has ayah timings. The separate California Murattal edition is from Assabile.com and has 113 Surahs (Surah 44 is missing); the Tarawih 1427 collection has 27 Surahs; and Al-Duri 'an al-Kisa'i has six Surahs. Salman Al-Utaybi has 75 Surahs in the MP3Quran catalog plus Surah 16 from Way2Quran.com, for 76 total. The California, Tarawih, Al-Duri, and Salman recordings have no verified matching ayah timings, so the app requires a complete Surah and labels caption boundaries approximate. Available Surahs are shown in the selector.

MP3Quran.net, Assabile.com, and Way2Quran.com provide streaming/download pages, but the project has not found a separate license authorizing redistribution of their recordings. Check the linked provider terms before publishing or redistributing audio or videos. A user-uploaded file must be licensed for its intended use. A network connection is needed for built-in recordings.
