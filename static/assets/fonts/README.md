# Bundled Arabic fonts

This directory includes Amiri, Noto Naskh Arabic, Noto Sans Arabic, and Noto Kufi Arabic in regular and bold weights. These fonts are bundled for both the Pillow renderer and the browser preview, so Arabic shaping and previews do not depend on fonts installed on the host. Noto fonts use the SIL Open Font License 1.1 in `../FONT-LICENSE.txt`; Amiri's authors and license are in `Amiri-OFL.txt` and are summarized in `../FONT-LICENSE.txt`.
